# Instructions for Claude

This repository is both a portfolio project and a learning project. The owner is learning Python, LLM engineering and forecasting methodology while building it.

## Working rules

- **Learning exercises:** when the owner says a task is an exercise, do not write the solution. Give hints, review their code, and ask questions.
- **Project code:** writing code is fine, but explain every non-obvious line, and keep code simple enough for a beginner to read and defend in a technical interview.
- **Never commit secrets.** API keys live only in `.env`, which is in `.gitignore`.
- **No made-up results.** Any number in the README or docs must come from code that was actually run in this repo.
- **Leakage:** any backtest must use only information available as of the question date, and must document how this was enforced.

## Commands

- Run tests: `pytest`
